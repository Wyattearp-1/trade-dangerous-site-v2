Where this data comes from

This is a static site. The route optimizer runs entirely in your browser against data/trade-data.json. A GitHub Actions workflow rebuilds that file on a schedule from public dumps and commits it back, so the live site stays reasonably fresh.

Supported bulk sources (choose when you trigger the workflow, or set TD_SOURCE):

  • Spansh — default. Full station + market dump from spansh.co.uk/dumps.
  • EDDBlink / Tromador — the same feed Trade Dangerous recommends (elite.tromador.com). Often smaller and better for frequent refreshes.

Inara does not publish a bulk market dump or an open bulk API suitable for offline routing (only a rate-limited CMDR/profile API). Instead, every station in the route results links to Inara so you can cross-check live prices and station details there.

Demo data ships in the repo so the site works the moment you open it, before the first scheduled rebuild finishes.

Unofficial fan tool inspired by Trade Dangerous. Not affiliated with Frontier Developments, Spansh, Inara, or Tromador.
