Reach per hop = jump range × jumps, measured in a straight line. 0 = same system only.

Credits per hour divides profit by an estimated trip time: about 50 s per jump, 2½ min per station stop, plus supercruise to the station. These are fixed estimates, not Inara’s numbers (Inara doesn’t publish its formula).

Real paths only count hops you can actually jump, one system at a time, and show the systems to pass through. Only systems in the data are used as waypoints, so a path can occasionally be longer than the true best.

Buying raises the price and selling lowers it as you use up a station’s stock or demand. This is an estimate (Elite doesn’t publish its formula); it matters most for big cargo holds.

Sell part of the hold at one station and the rest at a nearby second one when that earns more, for example when the best buyer only wants a few tons.

    How it works

    This is a static site. The route search runs entirely in your browser (in a background thread) against a market snapshot that a GitHub Actions workflow rebuilds from the public Spansh station dump.

    Goal: most credits. Every hop is scored by the real cargo profit it earns, and the search keeps the richest partial routes. Distance is only a reach limit; it is shown for information and never traded off against profit.

    Every station with a market is included and searchable. Prices far outside a commodity’s normal range are discarded as bad data, and routes ignore prices older than your “max price age” setting. Always sanity-check a route against live prices (every station links to Inara) before you commit your cargo.

    Live prices

    The snapshot is rebuilt from a nightly dump, so prices can be hours old. After each search the page automatically asks public community services (EDSM and Ardent, both fed by players’ game uploads, so usually minutes old) for the current markets of the stations on your routes, re-plans each route with them, and re-ranks the results. It repeats every 5 minutes while results are on screen. If a service is down or blocked, the page quietly keeps using the snapshot. This is as live as a website can get without a server listening to the game’s data feed.
